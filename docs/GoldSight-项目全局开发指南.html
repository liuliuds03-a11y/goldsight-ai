一、项目是什么

GoldSight AI 是一个以黄金为核心的全球多金属智能监测、分析与预测平台。

系统通过采集全球黄金相关数据（行情、宏观经济、利率、美元、美债、原油、美股、ETF、CFTC、央行购金、地缘政治、新闻等），经过数据清洗、指标计算、多个专业 Agent 并行分析、量化分析和 DeepSeek 大模型综合分析，形成可解释的黄金短期与长期研究结论。

核心价值：把分散在全球各市场的黄金相关信息自动汇总、清洗、分析、解释，而不是单纯展示行情。

重要声明：GoldSight 是研究与分析系统，预测具有概率性，不构成投资建议或收益保证。

六、预测输出标准

短期预测（1小时～5天）

  • 趋势：偏多 / 中性 / 偏空
  • 上涨 / 下跌 / 震荡概率
  • 置信度
  • 5 个支撑位 S1-S5（含依据）
  • 5 个阻力位 R1-R5（含依据）
  • 主要利多 / 利空因素
  • 预测失效条件

长期预测（1～12个月）

  • Bear / Base / Bull 三种情景
  • 各情景概率
  • 目标价格区间
  • 核心驱动因素
  • 主要风险与目标失效条件

研究报告标准

  • 先展示数据事实，再给分析结论
  • 必须区分：事实 / 模型输出 / AI 推断 / 不确定性
  • 每个结论必须可追溯到数据和指标
  • 不得把概率预测包装成确定性结果

九、协作规则

  1. 一次只做一个明确的小任务，不大范围重构
  2. 自检通过才能提交：编译/启动通过、测试通过、日志正常
  3. PM 验收后才进入下一步
  4. 不跨目录修改：需要跨模块时先报告 PM
  5. 敏感信息禁止提交 Git：API Key、密码等只写 .env
  6. 所有预测保留生成时间和输入数据版本，方便追溯
  7. 提交信息格式：feat / fix / test / docs / refactor / chore : 描述
  8. 善用 Skill 工具提升效率（见第十一章）

十一、Skill 效率工具指南

各 Agent 在开发过程中可以调用以下 Skill 来提升效率：

Skill 名称用途推荐 Agent
schedule创建定时/周期性任务（如定时数据采集、环境检查）环境配置、Backend
create-skill创建自定义 Skill，封装重复性工作为可复用技能所有 Agent
create-subagent创建专用子 Agent，处理特定子任务Backend、Frontend
canvas创建可视化 UI 原型/组件预览Frontend
vercel-deploy部署前端到 Vercel（后期演示用）Frontend、部署

使用建议

  • 环境配置 Agent：用 schedule 设置定时环境检查
  • Backend Agent：用 create-skill 封装数据采集逻辑为可复用 Skill；用 create-subagent 创建数据清洗子 Agent
  • Frontend Agent：用 canvas 预览 UI 组件和布局；用 create-skill 封装图表组件生成
  • Database Agent：用 create-skill 封装 Schema 生成和 Migration 脚本模板
  • 部署 Agent：用 schedule 设置定时容器健康检查；用 vercel-deploy 做前端演示部署
  • 版本管理 Agent：用 create-skill 封装提交规范检查
