# GoldSight AI V3.0 - 项目文档

本目录存放 GoldSight 项目的所有文档，由 PM 和各专业 Agent 共同维护。

## 目录结构

```
docs/
├── README.md               # 本文件
├── environment/            # 环境检查与配置记录
│   └── environment-report.md
├── architecture/           # 架构设计文档
├── api/                    # API 接口规范
├── data/                   # 数据源、数据字典、指标体系
└── development/            # 开发规范、流程文档
```

## 文档维护规则

- 每个 Agent 负责自己模块的文档更新
- PM 负责总体架构、流程和环境文档
- 所有文档使用 Markdown 格式
- 文档变更需与代码变更同步
