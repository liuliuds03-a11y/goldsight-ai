# Agent 提示词目录

本目录包含 GoldSight AI V3.0 项目中各专业 Agent 的任务提示词。

**使用方法**：将对应 Agent 的提示词文件内容**完整复制**，作为该 Agent 会话的第一条消息发送。

## 提示词列表

| 编号 | Agent | 文件 | 当前阶段任务 |
|------|-------|------|-------------|
| 01 | 环境配置 Agent | [01-环境配置Agent.md](./01-环境配置Agent.md) | 阶段 0：检查环境、安装 Docker、配置虚拟环境 |
| 02 | 后端开发 Agent | [02-后端开发Agent.md](./02-后端开发Agent.md) | 阶段 1：初始化 FastAPI 项目 |
| 03 | 前端开发 Agent | [03-前端开发Agent.md](./03-前端开发Agent.md) | 阶段 1：初始化 React + Vite 项目 |
| 04 | 数据库 Agent | [04-数据库Agent.md](./04-数据库Agent.md) | 阶段 1：设计数据库 Schema |
| 05 | 部署 Agent | [05-部署Agent.md](./05-部署Agent.md) | 阶段 0：验证 Docker 环境 |
| 06 | 版本管理 Agent | [06-版本管理Agent.md](./06-版本管理Agent.md) | 阶段 0：制定 Git 规范、整理首次提交 |

## 推荐执行顺序

1. **环境配置 Agent**（最先）— 确保开发环境完整可用
2. **版本管理 Agent**（同步）— 制定 Git 规范
3. **后端开发 Agent**（环境就绪后）— 初始化后端项目
4. **前端开发 Agent**（环境就绪后）— 初始化前端项目
5. **数据库 Agent**（可与后端并行）— 设计数据库
6. **部署 Agent**（Docker 安装后）— 完善服务编排

## 注意事项

- 每个 Agent 提示词已包含项目背景、具体任务、交付物要求和约束条件
- Agent 完成后会输出自检报告，请将报告转发给 PM（我）进行验收
- 如需调整任务，请先与 PM 沟通，不要自行修改提示词后发送
